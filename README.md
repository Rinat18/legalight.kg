# LegaLight — Corporate Legal Website ⚖️

Современный веб-сайт для юридической компании **LegaLight** (Бишкек, Кыргызстан).
Проект разработан с упором на скорость, SEO и современный дизайн.

## 🛠 Технологический стек (Tech Stack)
* **Framework:** Next.js 14 (App Router)
* **Styling:** Tailwind CSS
* **Language:** TypeScript
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Deployment:** Static Export (для хостинга Satcom/Plesk)

## ⚡ Особенности (Features)
* 🎨 **Современный UI/UX:** Адаптивный дизайн, плавные анимации появления.
* 📰 **Агрегатор новостей:** Автоматический парсинг экономических новостей (через RSS/Google News) с фильтрацией контента.
* telegram **Форма заявки:** Интеграция с Telegram API для мгновенного получения заявок от клиентов.
* 🗺 **Карта:** Интеграция с Google Maps/2GIS.
